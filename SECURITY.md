# Security policy

## Scope

This is a public case-study repository. It does not contain the production application, deployment configuration, credentials, customer data, payment code or private partner contracts. There is no runnable service in this repository.

Security reports concerning the TPTS Grid customer production surface, payment behaviour, private infrastructure or accidentally exposed information are nevertheless taken seriously.

## Report privately

Do **not** open a public GitHub issue, discussion or pull request for a suspected vulnerability.

Email [info@tptsnam.com](mailto:info@tptsnam.com) with the subject `SECURITY — TPTS Grid`. Include:

- the affected URL or surface;
- a concise description of the issue and its likely impact;
- safe reproduction steps;
- relevant timestamps and request identifiers, if available;
- your preferred contact details.

Do not include cardholder data, passwords, identity documents, access tokens, API keys or unrelated personal information. If sensitive evidence is necessary, ask for a secure exchange method first.

## Safe-harbour expectations

Please act in good faith:

- avoid privacy violations, disruption, social engineering and data destruction;
- use the minimum access necessary to demonstrate an issue;
- stop testing if you encounter personal, financial or confidential data;
- allow TPTS reasonable time to investigate before public disclosure;
- do not test third-party providers outside the scope of their own published policies.

TPTS will acknowledge a complete report through the available contact channel and coordinate next steps. This file does not create a bug-bounty programme or promise compensation.

## Repository hygiene

If you believe a secret or private file was committed here, report it immediately and do not copy, use or redistribute it. Removal from the latest Git revision is not sufficient remediation; exposed credentials must be revoked or rotated and repository history assessed.
