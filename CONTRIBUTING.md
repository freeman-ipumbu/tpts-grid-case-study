# Contributing

Thank you for taking an interest in TPTS Grid.

This repository is a **public product showcase**, not the production application and not an open-source distribution. Contributions are limited to improving the accuracy, clarity and accessibility of the case study.

## Helpful contributions

- corrections to public facts or broken official links;
- accessibility improvements to the documentation;
- clearer attribution for third-party tools or data;
- spelling, grammar and formatting fixes;
- respectful context about Namibian geography or tourism, with a reliable source.

## Out of scope

- requests for production source, infrastructure or database details;
- payment implementation examples or guesses about provider contracts;
- API keys, credentials, affiliate identifiers or partner documents;
- customer, property-owner or booking data;
- feature code, deployment workflows or reverse-engineered interfaces;
- scraped accommodation inventory;
- claims that a place, channel or provider is integrated without verifiable approval.

## Before opening a pull request

1. Keep the change focused on the case study.
2. Link to an authoritative public source for factual changes.
3. Confirm the contribution contains no personal, financial, confidential or security-sensitive information.
4. Preserve the distinction between a destination anchor, an applicant, a verified property and live bookable inventory.
5. Do not add third-party logos or copyrighted media without documented permission.

By contributing, you confirm that you have the right to submit the material and permit TPTS Financial Technology Group to use it in this case study. Acceptance is at the maintainers' discretion and does not change the repository licence.

For product or partnership enquiries, use [info@tptsnam.com](mailto:info@tptsnam.com) rather than a GitHub issue.
