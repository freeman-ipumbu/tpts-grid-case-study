## Interpretation rules

- “Path verified” means an official application or documentation path exists; it does **not** mean TPTS has been approved.
- “Implemented” describes a capability in the private product; it does not make this repository deployable.
- “Activation gated” means the experience boundary exists, but production use still depends on commercial, legal, security and provider-specific requirements.
- Provider pages can change. Re-check this register before making a new public status claim.
